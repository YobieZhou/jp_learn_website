# 国际交流基金《いろどり 生活の日本語》官方音频素材调查

调查日期：2026-08-26

调查范围仅限国际交流基金及《いろどり 生活の日本語》官方网站的一手资料。本文件是项目选材风险判断，不构成法律意见。

## 结论摘要

1. 《いろどり》官方确实提供 MP3 音频，可按教材级别整包下载、按课下载，也可在官方网页逐条播放。文件按“级别 → 课 → 教学活动”组织，文件名中的 `kiku`、`hanasu`、`kaiwa`、`kotoba`、`katachi` 等分别对应听、说、会话、词汇、表达形式等教材活动。
2. **没有发现可以直接按一个假名映射一个独立音频文件的官方素材集。**《入门》第 1 课虽有 `hiragana1`～`hiragana4` 等平假名音轨，教材页也覆盖清音、浊音、半浊音和拗音，但官方播放页把它们编成少量组合音轨，并未为「あ」「か」「が」「きゃ」等每个项目分别提供独立文件。因此它们不能不经裁剪就直接替换本站现有的逐假名音频。
3. 官方条款明确允许把资料保存到个人或机构设备，并用于课堂（包括在线课堂）和个人学习；但没有明确授权把原 MP3 裁剪、拆分后作为本站自己的音频资产重新托管到公开 GitHub 仓库或 GitHub Pages。
4. 保守结论：**可以把官方原始音频下载到本机进行个人试听和技术评估；不要把原音频或裁剪后的逐假名文件提交到公开仓库或部署到 GitHub Pages，除非先取得国际交流基金的明确书面许可。**

## 1. 官方下载入口与文件组织

《いろどり》官方说明，教材由“入门（A1）”“初级 1（A2）”“初级 2（A2）”“初中级（A2/B1）”构成；各级包含教材 PDF 和第 1～18 课 MP3。官网同时说明音频既可下载，也可流式播放。

以“入门”为例，官方页面提供：

- 全部音频一括下载：一个 MP3 ZIP；
- “教室の日本語”以及第 1～18 课：每部分分别提供 MP3 ZIP；
- 每课的“音声ファイル再生（MP3）”页面：按教学活动列出音轨。

可核验的直接示例：

- 入门全部音频 ZIP：`X_audio_all.zip`；
- 入门第 1 课 ZIP：`01/X_audio_L01.zip`；
- 入门第 1 课播放页列出 `X_[01-01]_kiku.mp3`、`X_[01-06]_hanasu1-1.mp3` 等活动音频，以及 `X_[01-30]_hiragana1.mp3`～`X_[01-33]_hiragana4.mp3`、`X_[01-34]_hiragana_nobasu.mp3`、`X_[01-35]_hiragana_tsumaru.mp3`；
- 初级 1 第 1 课播放页列出 `kaiwa`、`hanasu`、`kiku`、`katachi`、`kotoba` 等类别，说明通用组织单位是教材活动或词汇/会话片段，而非单个假名。

## 2. 是否存在逐个假名的官方发音

### 核对结果

**未发现“一个假名对应一个独立 MP3”的官方文件集。**

《入门》第 1 课教材中的“ひらがなのことば”确实展示了平假名表，并包括：

- 五十音清音；
- 浊音与半浊音；
- `しゃ／しゅ／しょ`、`ぎゃ／ぎゅ／ぎょ` 等拗音；
- 长音和促音练习。

但是，与这张表对应的官方播放页只有 `hiragana1`～`hiragana4` 等组合音轨，而不是为表中每个假名分别提供 MP3。第 2 课承担片假名学习，官方文件仍按课和练习组织。由此可得：官方有“教授假名的音频”，但没有可直接映射到本站五十音、浊音、半浊音和拗音按钮的“逐假名独立音频”。

若要把这些组合音轨变成本站所需的逐假名文件，必须定位时间点并裁剪/拆分，这属于对官方音频的复制和改动，需继续受利用条款约束。

## 3. 利用条款：下载、裁剪与公开再托管

《いろどり》官网“このサイトについて”中的“著作権・利用指針”明确写明：

- 网站中的文本、图版、图片、音频等著作权或知识产权归国际交流基金日本语国际中心、原作者或其他权利人；
- 除学校等教育机构使用或私人使用外，不得转载、复制或改编全部或部分网站资料；
- 所称教育或私人使用包括保存到机构或个人的电脑、平板、手机等设备，以及用于课堂（含在线课堂）或个人学习；
- 使用网站资料制作并公开独自的教学资料、工作表等时，应当免费并注明来源；
- 不得利用网站资料制作与《いろどり》完全无关的另一套教材。

### 对本项目的保守解释

“免费下载”和“可以在个人设备保存”不等于获得了任意改编或再分发许可。条款虽然允许在特定条件下公开自行制作的教学资料或工作表，但**没有明确说明可以把官方 MP3 本体裁剪、拆分后重新上传到公开代码仓库或网站**。音频还可能涉及旁白演员及其他权利人的权益。

因此：

- 下载官方原始 MP3 到本机并个人试听：有明确条款依据；
- 在本机为了个人评估而临时裁剪且不向他人提供：风险明显低于公开部署，但不应把临时结果对外传播；
- 把完整官方 MP3 提交到公开 GitHub：构成复制和公开再托管，条款未明确授权；
- 把官方 MP3 裁成单假名后提交或部署：同时涉及复制、改编和公开再托管，条款未明确授权，风险更高；
- 免费、注明来源并不能自动补足对音频本体重新托管和改编的授权。

在取得书面许可前，公开版本应继续使用许可清晰的自制、委托制作或合成语音素材；《いろどり》音频只用于本地原始文件试听。若一定要公开使用，应通过官网联系入口向国际交流基金确认“裁剪为逐假名音频并在公开 GitHub Pages 免费发布”是否被允许。

## 4. 本地试听与公开部署的风险差异

| 场景 | 条款依据或缺口 | 保守判断 |
| --- | --- | --- |
| 下载原始 ZIP/MP3 到个人电脑 | 条款明确把保存到个人设备、个人学习列为允许使用 | 可用于本地试听 |
| 本地临时裁剪，只供本人评估且不分发 | 接近私人使用，但裁剪属于改动；条款没有针对这种技术测试单独说明 | 风险较低，结果不要外传 |
| 将原始 MP3 放入公开 GitHub/GitHub Pages | 公开复制和再托管未获明确授权 | 不建议 |
| 将音频拆成逐假名文件后公开部署 | 同时涉及改编、复制、公开再托管；无明确授权 | 不应实施，除非取得书面许可 |

## 最终建议

本项目不应把《いろどり》的音频作为五十音逐假名音源公开部署。原因有二：第一，官方没有提供可直接映射的逐假名独立文件，必须自行拆分；第二，官方条款没有明确授权把拆分后的音频重新托管到公开 GitHub Pages。可以下载官方原始音频做本地试听对比，但在获得明确书面许可前，应把它严格留在个人本地环境中。
